# 多彩文本 Colorful Text

一个 [SillyTavern（酒馆）](https://github.com/SillyTavern/SillyTavern) 第三方扩展：在不改动酒馆主题的前提下，分别自定义 **主要文本、斜体文本、下划线文本、引用文本**（含双引号内的对话内容）的颜色，支持 **跟随酒馆主题 / 纯色 / 渐变** 三种模式。

## 功能特性

- 四类文本独立配色，互不影响（面板为四个横向标签页，点击切换）：
  - **主要文本**：普通叙述与描写段落
  - **斜体文本**：`*内心独白*` / `_动作描写_`（`<i>` / `<em>`）
  - **下划线文本**：`<u>` / `<ins>` 强调词句
  - **引用文本**：Markdown 引用块（`<blockquote>`）与双引号内的对话（`<q>`，同时兼容中文 `“ ”` 与英文 `" "`）
- 每一类都可以独立选择：
  - **跟随酒馆主题**：完全使用酒馆当前主题对应变量的颜色，不写入任何内联颜色，切换主题自动跟随
  - **纯色**：自定义固定单色
  - **渐变**：支持 2–4 个颜色色标；主要文本 / 下划线 / 引用可用 **0–360° 渐变角度**（0° 自下而上、90° 自左而右、180° 自上而下），滑杆与数字框双向联动，渐变预览条实时按角度渲染；两种循环方式可选：
    - **段落 / 句子循环**：主要文本 / 下划线 / 引用用 CSS 原生线性渐变 `linear-gradient(角度, 色标…)` + `background-clip: text`；斜体句子按本句一次走完一遍色标、逐字符水平插值（不使用背景裁剪，不提供角度设置）
    - **字符长度**：每 N 个字（2–999，默认 30）重复走完一遍色标，逐字符插值上色
- 代码、链接、加粗、标题、图片等元素保持酒馆原色不受影响。
- 设置面板跟随酒馆主题配色与字号：面板颜色全部取自酒馆主题变量，字号继承酒馆全局字号（`--mainFontSize`），切换主题或调整酒馆字体大小时面板自动跟随；手机窄屏自动切换为纵向布局。
- 设置自动持久化，聊天加载、发送、编辑、滑动切换、新消息渲染等事件都会自动重新染色；重复应用保证幂等。
- **性能优化**：消息级指纹缓存——设置与文本都未变化的消息直接跳过；段落 / 句子循环由浏览器原生渲染，长聊天与流式生成更流畅。指纹比对之外另检测染色产物是否仍在，被酒馆结束渲染清空时自动补染，不会退回默认色。段落 / 句子渐变的透明填充色不会泄漏到内部主题色 / 纯色子元素，末字与斜体、下划线、引用片段不再发黑缺色；斜体句子循环改逐字符纯色插值，绕开 `background-clip: text` 背景盒，行末末字笔画不会再被裁掉。

## 安装方法（手机端 / 电脑端通用）

1. 在酒馆顶部菜单栏打开 **Extensions（扩展）** 页面。
2. 点击 **Install Extension（安装扩展）**。
3. 将本仓库的 Git 地址粘贴到输入框：
   ```
   https://github.com/yg0108011/st-colorful-text.git
   ```
4. 确认安装，完成后在 **Extensions → Installed Extensions** 列表中找到「多彩文本 Colorful Text」，勾选启用即可。
5. 配色面板位于右侧设置栏「Extensions」分类下；修改后即时生效并自动保存。

> 手机端酒馆与电脑端使用同一套扩展安装流程，本扩展不依赖额外权限或本地文件。

## 面板说明

- **启用多彩文本**：总开关，关闭后完全恢复酒馆原色。
- **分类标签页**：主要文本 / 斜体文本 / 下划线文本 / 引用文本 四个横向标签，点击切换本类设置。
- **配色模式**：跟随酒馆主题 / 纯色 / 渐变，后两种模式对应的控件随模式切换显示。
- **纯色颜色**：折叠状态为整齐一行（小色块 + 深色色号框 + 删除按钮）；点击色块即在该行下方展开深色圆角选色盘（SV 调色盘 + 彩虹色相条 + R/G/B 三字段，标签在框上方、数字居中），选色盘处于面板文档流内，不弹出浮层，窄屏与手机端不会被抽屉裁剪；色号框支持手动填写 `#RGB` / `#RRGGBB`（可省略 `#`），失焦自动归一化为 6 位小写色号，非法输入标红并还原，取色盘回写不会覆盖正在输入的内容。
- **渐变颜色**：2–4 个颜色色标，每个色标折叠为整齐一行、点击色块展开同一套选色盘并支持手动色号，可增可删，下方渐变预览条实时显示配色。
- **循环方式**：仅渐变模式可见，选项文案随类别区分：
  - **段落 / 句子循环**：主要文本按段落、下划线 / 引用按句子铺一遍 CSS 渐变并保留角度；斜体句子按本句逐字符水平插值。
  - **字符长度**：按自定义字符数重复走完一遍色标。
- **循环字符数**：仅「字符长度」可见，取值 2–999，默认 30。
- **渐变角度**：主要文本 / 下划线 / 引用的段落 / 句子循环可见；斜体句子循环为水平逐字插值，不显示角度。滑杆拖到哪就是几度，也可直接在数字框输入 0–360 之间的整数；超出范围自动取模回卷（如 400° 记为 40°，-90° 记为 270°）。
- **实时预览**：面板内直接查看当前四类配色效果。
- **应用到当前聊天**：手动重染当前聊天全部消息。
- **恢复默认颜色**：全部类别重置为「跟随酒馆主题」。

## 渐变规则

### 段落 / 句子循环

- 主要文本 / 下划线 / 引用使用浏览器原生 `linear-gradient(角度, 色1, 色2, …)`，并以 `background-clip: text` 裁剪到文字上，因此**角度即渐变在文字块上的走向**：
  - `0deg`：自下而上
  - `90deg`：自左而右（默认）
  - `180deg`：自上而下
  - `270deg`：自右而左
  - 其他任意角度均可，例如 `45deg` 左下到右上、`225deg` 右上到左下。
- 斜体句子不使用背景裁剪：本句文本从色标起点到终点逐字符纯色插值，颜色沿阅读方向水平过渡，不受行末背景盒边界影响，末字笔画完整；也不套用角度设置。
- 主要文本按段落分别铺一遍渐变；下划线 / 引用以各自句子（元素）为单位铺渐变；普通段落里裸写的双引号对话以该引号片段为单位套用引用渐变。

### 字符长度

- 从类别起始位置连续计数，每 `cycleLength` 个字走完一遍色标后重复，色标之间逐字符插值过渡。
- 主要文本与裸写双引号对话各自独立计数；斜体 / 下划线 / 引用在本元素内部连续计数。

## 文件结构

```
st-colorful-text/
├── manifest.json      # 扩展清单（酒馆扩展管理器识别用）
├── index.js           # 酒馆胶水层：设置持久化、面板 UI、事件绑定、DOM 观察器
├── engine.js          # 纯逻辑引擎：设置校验、CSS 渐变 / 逐字符插值与幂等重置
├── settings.html      # 设置面板骨架
├── style.css          # 面板样式（主题变量 + 继承字号）
├── test/              # 本地自动化测试与渲染预览（仅开发用，酒馆加载时不引用）
├── README.md
└── LICENSE
```

## 本地开发与测试

引擎逻辑与酒馆运行时解耦，可在 Node 环境独立测试（`test/` 目录仅开发用，安装到酒馆后可忽略）：

```bash
cd test
npm install
node --test engine.test.mjs
```

## 更新记录

- **1.3.8**：重做取色界面布局与外观——折叠状态恢复整齐一行（小色块 + 深色色号框 + 灰色删除按钮），与设置面板原有 UI 风格统一；点击色块后才在该行下方独占一行展开深色圆角选色盘（SV 大方块 + 彩虹色相条 + R/G/B 三字段，标签在框上方、数字居中），不再像 v1.3.7 那样把色号框与删除叉挤到面板右侧悬空、相邻色块并排再展开第二个面板；选色盘仍处于文档流内、不弹出浮层，窄屏与手机端不会被抽屉裁剪；折叠行色块、色号框、删除按钮尺寸按目标界面比例重写，补充 `[hidden]` 折叠规则与展开行独占整行宽度的布局规则。
- **1.3.7**：取色方案改为面板内自绘调色盘，弃用酒馆 `<toolcool-color-picker>` 组件弹窗——组件弹窗是其 shadow DOM 内的绝对定位浮层，插件位于纵向滚动的 Extensions 抽屉中，按 CSS 规范横向溢出必然被裁，外部又无法把浮层改为视口固定定位，手机竖屏上调色盘会被右缘裁掉、字段压在预览正文上。现改为点击色块在该行下方展开的自绘面板（SV 调色盘 + 色相条 + R/G/B 字段），全部处于文档流内，不跳出抽屉、不受裁剪，手机与桌面通用；同时切断色号框与取色盘的双向同步回环：取色盘回写输入框时若用户正聚焦在色号框内则跳过覆盖，修复手动输入时删字被补回、删不掉的问题。纯色与每个渐变色标统一使用同一套自绘调色盘，手动色号输入、非法标红与失焦还原逻辑保持不变。
- **1.3.6**：取色界面更换为酒馆自带的 `<toolcool-color-picker>` 组件（与右侧「主题颜色」面板同款：SV 调色盘 + 色相条 + 透明条 + Hex/R/G/B/A 五输入框），不再经过当前主题接管原生 `<input type="color">` 弹出的「建议 / 自定义」预设色板与「取消 / 设置」模态窗；纯色与每个渐变色标统一使用该组件，旁边手动色号输入框、双向同步、非法标红与失焦还原逻辑保持不变；组件未注册的旧版酒馆自动回退原生取色器。
- **1.3.5**：彻底修复斜体句子循环末字像被裁掉一节——`background-clip: text` 的裁剪边界走元素盒 / 行盒而非字形真实轮廓，斜体合成倾斜向右上伸出的笔画在行末边界被裁；v1.3.4 的内联水平余量补偿在 inline 元素上未能有效外扩裁剪盒。现改为斜体句子按本句一次走完一遍色标、逐字符纯色插值上色，与已验证正常的字符长度循环同一渲染路径，不再写背景渐变、透明填充与盒补偿，从机制上绕开背景裁剪；代价是斜体句子循环不再支持渐变角度（退为水平方向），面板斜体句子循环下自动隐藏角度滑杆，主要文本 / 下划线 / 引用及其余循环方式不受影响。
- **1.3.4**：修复斜体句子循环（段落渐变）末字像被裁掉一节——斜体是 inline 元素，字形合成倾斜向右上伸出，而 `background-clip: text` 的背景盒按未倾斜的字符盒计算，末字右侧伸出的笔画落在背景盒外、透出深色背景；现在给斜体渐变元素左右各留 0.16em 水平余量外扩背景盒，负 margin 抵消对行宽与换行的影响，主要文本、下划线、引用与字符长度循环不受影响。
- **1.3.3**：修复段落 / 句子循环下末字与子元素发黑缺色——父级渐变用 `background-clip: text` + 透明文字填充，该透明色会沿继承链泄漏到内部「跟随主题」「纯色」的斜体 / 下划线 / 引用 / 双引号片段，盖过其颜色使笔画透出深色背景；现在主题色与纯色子元素显式把填充色设为 `currentColor` 阻断继承泄漏，字符长度循环不受影响。
- **1.3.2**：修复流式生成结束后消息退回酒馆默认色——酒馆最终 Markdown 渲染会替换 `innerHTML`、冲掉染色产物，而消息指纹只比对设置与文本，误判为无需重染；现在检测到染色产物被清空时强制重染，并在生成结束后延迟补染两次兜底。
- **1.3.1**：循环方式选项按类别改名——主要文本为「段落」，斜体 / 下划线 / 引用为「句子」，另一选项统一为「字符长度」；后端取值与染色逻辑不变。
