# 多彩文本 Colorful Text

一个 [SillyTavern（酒馆）](https://github.com/SillyTavern/SillyTavern) 第三方扩展：在不改动酒馆主题的前提下，分别自定义 **主要文本、斜体文本、下划线文本、引用文本**（含双引号内的对话内容）的颜色，支持 **跟随酒馆主题 / 纯色 / 渐变** 三种模式。

## 功能特性

- 四类文本独立配色，互不影响：
  - **主要文本**：普通叙述与描写段落
  - **斜体文本**：`*内心独白*` / `_动作描写_`（`<i>` / `<em>`）
  - **下划线文本**：`<u>` / `<ins>` 强调词句
  - **引用文本**：Markdown 引用块（`<blockquote>`）与双引号内的对话（`<q>`，同时兼容中文 `“ ”` 与英文 `" "`）
- 每一类都可以独立选择：
  - **跟随酒馆主题**：完全使用酒馆当前主题对应变量的颜色，不写入任何内联颜色，切换主题自动跟随
  - **纯色**：自定义固定单色
  - **渐变**：自定义 2–4 个颜色；循环方式二选一：**字符长度循环**（每 N 个字一个循环，N 可自定义 2–999，默认 30）或 **整段话循环**（主要文本按自然段，斜体 / 下划线 / 引用按本句话（本元素），各自独立走完一遍色标）
- 渐变模式下整段文字逐字符上色，**渐变覆盖全部字符，不留纯色残留**；代码、链接、加粗、标题、图片等元素保持酒馆原色不受影响。
- 设置面板跟随酒馆主题配色与字号：面板颜色全部取自酒馆主题变量，字号继承酒馆全局字号（`--mainFontSize`），切换主题或调整酒馆字体大小时面板自动跟随；手机窄屏自动切换为纵向布局。
- 设置自动持久化，聊天加载、发送、编辑、滑动切换、新消息渲染等事件都会自动重新染色；重复应用保证幂等，不会产生嵌套包裹。

## 安装方法（手机端 / 电脑端通用）

1. 在酒馆顶部菜单栏打开 **Extensions（扩展）** 页面。
2. 点击 **Install Extension（安装扩展）**。
3. 将本仓库的 Git 地址粘贴到输入框：
   ```
   https://github.com/yg0108011/st-colorful-text.git
   ```
4. 确认安装，完成后在 **Extensions → Installed Extensions** 列表中找到「多彩文本 Colorful Text」，勾选启用即可。
5. 配色面板位于右侧设置栏「Extensions」分类下；修改后即时生效并自动保存。

> 手机端酒馆与电脑端使用同一套扩展安装流程，本扩展不依赖额外权限或本地文件。

## 面板说明

- **启用多彩文本**：总开关，关闭后完全恢复酒馆原色。
- **配色模式**：跟随酒馆主题 / 纯色 / 渐变，三类控件随模式切换显示。
- **纯色颜色**：当前类别的固定颜色选择器。
- **渐变颜色**：2–4 个颜色色标，可增可删，下方渐变预览条实时显示循环配色。
- **循环方式**：仅渐变模式可见，选择「字符长度循环」或「整段话循环」。
- **循环字符数**：字符长度循环下生效，可填 2–999，默认 30。
- **实时预览**：面板内直接查看当前四类配色效果。
- **应用到当前聊天**：手动重染当前聊天全部消息。
- **恢复默认颜色**：全部类别重置为「跟随酒馆主题」。

## 渐变规则（四类文本各自独立设置）

- **字符长度循环**：每 N 个字符（含空格与标点）走完一遍色标，达到第 N 个字后回到第一个颜色重新循环；N 可在面板填 2–999，默认 30。
- **整段话循环**：
  - **主要文本**：以每个 `<p>` 自然段为单位，段首取第一个色标、段尾取最后一个色标，中间线性过渡；段内引号对话不打断主文本梯度，新段落重新从第一个色标开始。
  - **斜体 / 下划线 / 引用**：以本句话（本 `<i>` / `<em>` / `<u>` / `<ins>` / `<q>` / `<blockquote>` 元素）为单位，句首到句尾走完一遍色标，句与句各自独立；普通段落里的双引号对话以该引号片段为单位。
- 颜色在相邻色标之间线性插值；字符顺序即颜色过渡顺序。
- 字符长度循环下，斜体 / 下划线 / 引用元素内部各自独立循环计数。

## 文件结构

```
st-colorful-text/
├── manifest.json      # 扩展清单（酒馆扩展管理器识别用）
├── index.js           # 酒馆胶水层：设置持久化、面板 UI、事件绑定、DOM 观察器
├── engine.js          # 纯逻辑引擎：设置校验、颜色插值、DOM 染色与幂等重置
├── settings.html      # 设置面板骨架
├── style.css          # 面板样式（主题变量 + 继承字号）
├── test/              # 本地自动化测试与渲染预览（仅开发用，酒馆加载时不引用）
├── README.md
└── LICENSE
```

## 本地开发与测试

引擎逻辑与酒馆运行时解耦，可在 Node 环境独立测试（`test/` 目录仅开发用，安装到酒馆后可忽略）：

```bash
cd test
npm install
node --test engine.test.mjs
```

## 兼容性

- 最低酒馆客户端版本：`1.12.0`
- 主题变量映射：主要文本 `--SmartThemeBodyColor`、斜体 `--SmartThemeEmColor`、下划线 `--SmartThemeUnderlineColor`、引用 `--SmartThemeQuoteColor`。
