点击上方四个分类标签切换设置。渐变模式支持两种循环方式：「段落 / 句子循环」中主要文本按段落、下划线 / 引用按句子各自走完一遍 CSS 线性渐变（2–4 色，角度 0–360° 可调，0° 自下而上、90° 自左而右、180° 自上而下）；斜体句子为避免背景盒裁掉倾斜伸出的笔画，整句逐字符按角度走向取色，水平 / 斜角方向过渡、上下走向整句均匀。「字符长度」按自定义字符数（2–999）重复走完一遍色标。选择“跟随酒馆主题”时完全使用酒馆当前主题配色。颜色默认显示为整齐一行（色块 + 色号框 + 删除按钮），点击色块即在该行下方展开选色盘（SV 调色盘 + 色相条 + R/G/B），也可直接在色号输入框填写色号（#RGB / #RRGGBB）。颜文字里成对星号被 Markdown 误配成斜体时，纯符号碎片以及被从中间劈成多段、同层交错的含汉字斜体段都会自动跟随主要文本配色，渐变不在颜文字处中断；独立的真斜体独白仍按斜体配色。
